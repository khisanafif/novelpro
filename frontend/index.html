➕ Tambah & Unduh Model GGUF Kustom dari HuggingFace

Tempelkan URL langsung ke file .gguf (misalnya dari repositori bartowski, unsloth, atau mradermacher) atau isi format owner/repo beserta nama file GGUF-nya. Studio otomatis memverifikasi URL dan mengunduh secara resumable ke folder .

Sumber HTTPS tepercaya: huggingface.co, hf.co, github.com
💡 Cara Menambahkan Model Secara Manual (Tanpa Unduh Lewat Web):

Salin file .gguf mana pun hasil unduhan browser/IDM ke folder (atau biarkan di ~/Downloads), lalu buka tab 💾 Model Lokal dan klik tombol 🔄 Refresh Status.

🌐 Hubungkan Model Online atau Server Kompatibel Lain

Cocok bila ingin kecepatan instan di laptop hemat RAM: hubungkan ke OpenRouter, Google Gemini, Groq, OpenAI, DeepSeek, Mistral, Anthropic Claude, atau server LAN/lokal seperti Ollama & LM Studio.
